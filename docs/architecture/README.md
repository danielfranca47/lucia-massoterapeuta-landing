# docs/architecture — Guia

## O que é esta pasta

Documentos que descrevem seções ou comportamentos não-óbvios da landing page
que são grandes demais pra caber como uma linha no `CLAUDE.md` (ex.: como o
motor de disponibilidade do calendário funciona, como o handoff pro WhatsApp
é montado). São espelhos do estado atual — sem histórico de implementação.

Convenções que valem pra página em geral (não uma seção específica) ficam
direto no `CLAUDE.md`, seção "Convenções ao editar" — não aqui.
